# Movie But Ads

Movie But Ads 是一组用户脚本，旨在提升用户在海外电影网站上的观看体验。这些脚本可以去除广告、改善功能，并优化用户界面，让观影更加流畅。

主要功能：

- 移除常用海外电影网站上的广告
- 增强视频播放器控制，支持快捷键操作

专为追求更干净、更流畅观影体验的用户设计。

## 使用方法

### LibreTV

LibreTV 适配生成 `dist/libretv.user.js`。先把
`src/sites/libretv/config.yaml` 的 `match` 占位地址替换成自己的入口，例如
`https://你的域名:8443/*` 或 `http://localhost:18080/*`，再运行 `yarn build`，
将生成的脚本安装到 Tampermonkey / Violentmonkey。占位地址不会匹配实际站点。
安装脚本的浏览器才会获得这些功能；电视上的浏览器需单独安装。

LibreTV 适配支持 `1`–`5`、`-` / `_`、`=` / `+` 的倍速快捷键，
`,` / `.` / `<` / `>` 的跳转，以及 `P`（不按 Shift）的画中画；最低倍速为 0.25。
空格、方向键和 `F` 继续由 LibreTV 自己处理，避免重复触发。
输入框、可编辑区域、按钮、滑块和 Ctrl / Command / Alt 组合键不会触发增强快捷键。
此适配不启用公共脚本的音频延迟和快速搜索功能。

脚本通过 ArtPlayer 容器内的标准 `<video>` 接口操作，每次按键重新寻找当前视频，
因此换集、换源及 SPA 导航无需重复注入。普通 LibreTV 更新无需重建或重装脚本；
如果上游更换播放器容器或快捷键，需要复验并调整适配。
脚本自身更新时重新构建并安装，保留自己的 `config.yaml` 中的 `match`；
直接安装仓库的默认构建产物会重新带入占位地址。

## 快捷键

以下是已实现的快捷键列表：

- `1` 到 `5`：设置指定的播放速度
- `-` / `_`：播放速度每次降低 0.25，最低为 0
- `=` / `+`：播放速度每次增加 0.25，最高为 10
- `F`：切换全屏模式
- `P`：切换画中画模式
- `,`：后退 10 秒
- `.`：前进 10 秒
- `<`：后退 20 秒
- `>`：前进 20 秒
- `C`：启用音频延迟调整
- `[`：减少音频延迟 0.1 秒
- `]`：增加音频延迟 0.1 秒
- `Q`：打开带搜索历史的快速搜索框
  - `Tab` / `Shift+Tab`（或 `↓` / `↑`）：在输入框和历史记录之间移动
  - `Enter`：搜索输入的关键词，或选中的历史记录
  - `Delete` / `Backspace`：删除选中的历史记录
  - `Esc`：关闭

这些快捷键可以帮助您更方便地控制视频播放，提升您的观影体验。
